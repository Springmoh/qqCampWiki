# 使用说明总览

这一部分写给**用网站的人**：营员、关主、Game Master、节目组和管理员。不需要懂电脑，照着截图做就可以。

| 你是谁 | 你用的画面 | 看哪一份 |
| --- | --- | --- |
| 营员（小组） | 手机上的 QQ-TNG 钱包和 Game Stations | [营员 Player](player.md) |
| 关主（关卡的人） | 关卡笔电上的 Station 页面 | [关主 Station](station.md) |
| 关卡负责人 | 手机上的 Game Master 页面 | [Game Master](gamemaster.md) |
| 礼堂队列组 | 电脑上的 Event Team 页面 + 手机签到页 | [节目组 Event Team](eventteam.md) |
| 管理员 / 技术团队 | 电脑上的 Console | [管理员 Console](console.md) |

## 营会当天的三个提醒

1. **先发奖励，再离开关卡。** Game Master 只能把奖励发给「现在站在他关卡里」的小组。营员要先在
   QQ-TNG 的转帐记录看到那一笔，再 Check Out；Game Master 也请记得「先发放，再 Release」。
2. **转出去的钱收不回来。** 转钱之前看清楚对方组名和金额。
3. **画面跳出要你做的事，照着做就好。** 例如红色倒计时、「需要清除缓存」的窗口（见下面）。

## 每个画面都可能出现：「需要清除缓存」

营会进行中如果技术团队更新了网站，所有打开着的画面（营员手机、关卡笔电、Game Master、节目组、Console）
都会跳出一个窗口，写着 **需要清除缓存**，只有一个按钮 **好**。按 **好** 之后画面会自己重新载入，
**帐号和钱包都不会受影响**。这个窗口关不掉，一定要按 **好** 才能继续用。
