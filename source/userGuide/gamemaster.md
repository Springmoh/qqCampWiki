# Game Master：管关卡、发奖励

看自己关卡里的小组、帮小组 Check In、显示关卡 QR、发奖励、必要时把小组放出关卡。

## 1. 登录 Sign In

用手机打开技术团队给你的 Game Master 网址，用营会给你的 **Game Master 帐号** 登录（营员的帐号在这里登不进去）。

登录后有两个分页：**Overview**（看关卡和小组）和 **Wallet**（发奖励）。
每个标题旁边的 **(i)** 是说明，手指点一下就会显示。

:::{note}
密码连续输错几次，帐号会暂时被锁住，之后就算密码打对也进不去。不用自己重设，找技术团队解锁。
:::

## 2. Overview：你的关卡

**你的 GAME STATIONS** 只列出分配给你的关卡。每张卡片：

- 右上角 **2/4**：现在几个小组 / 最多几个。
- 每个小组一行：组名、进来多久、目前余额、目前分数，右边是 **Release**。
- **显示 QR**：在你手机上显示这一关的打卡 QR（第 3 节）。
- **选择小组** + **Check In**：帮小组打卡进来（第 4 节）。
- **全部 Release**：把这一关所有小组放出去（第 5 节）。

## 3. [若 NFC 无法使用] 显示 QR：用你的手机给小组扫

关卡笔电不在身边、或想让小组在别的地方打卡时，按关卡卡片上的 **显示 QR**，手机会全屏显示这一关的打卡 QR。
小组用自己的手机扫它，就会 Check In（已经在这一关就会 Check Out）。看完按 **关闭**。

- 只能显示**你自己关卡**的 QR。
- 每一次显示都会记录下来（技术团队看得到）。所以不要把 QR 截图传给别人。
- 如果没有看到这个按钮，代表技术团队关掉了这个功能。

```{figure} images/gm-qr.png
:class: phone

显示 QR：小组用手机扫
```

## 4. Check In：帮小组 Check In

如果小组手机有问题：没网、没电、扫不到 QR 时，你可以帮他们 Check In：

1. 在关卡卡片按 **选择小组**，会跳出一个名单（每组前面有它的表情），只列出**现在不在任何关卡里**的小组。
2. 点要进来的小组，再按 **Check In**。

位子满了、或那个小组正在别的关卡，会被挡下来。如果没有看到这个选单，代表技术团队关掉了这个功能。

```{figure} images/gm-pick.png
:class: phone

选择小组：跳出的名单
```

## 5. Release / 全部 Release：把小组放出关卡

正常情况小组自己扫 QR 或按 Check Out 出去就好。遇到手机没电、扫不到、人已经走了但系统还显示在里面，就用：

- **Release**：把这一个小组放出这一关。
- **全部 Release**：把这一关所有小组放出去，通常是一轮结束时用。

按下去会先跳出确认。放出去之后位子就空出来，下一组可以进来。

:::{important}
**先发奖励，再 Release。** 奖励只能发给「现在站在你关卡里」的小组。一旦 Release，就要等他们重新进来才能发。
:::

## 6. 小组和流程图

Overview 下面是全营小组的名单，显示状态（游戏中 / 空闲 / 在礼堂……）、余额和分数。
点一个名字，流程图会圈出这个小组现在走到哪一格，箭头是接下来可能发生的事。
这一部分**只能看、不能改**，不会有人不小心动到小组的状态。

## 7. Wallet：发奖励

1. **小组**：只会列出现在站在你关卡里的小组。名单是空的，代表现在没有人在你的关卡。
2. **金额**：奖励多少钱。
3. **注释**：写清楚原因，例如「Water Relay 第一名」。小组在自己的转帐记录看得到这行字。
4. 按 **发放**，确认后就发出去。

你的钱包没有上限，发奖励不会把你的余额扣光；小组付给你的钱（入场费、罚款）会进到你的钱包。
下面的 **记录** 是你的收支：发出去的奖励和小组付给你的钱。

```{figure} images/gm-wallet.png
:class: phone

Wallet：选小组、填金额和原因、发放
```

发完奖励，请提醒小组：自己打开 QQ-TNG 的转帐记录确认收到了，再 Check Out 离开。

:::{note}
**发错金额怎么办？** Game Master 页面不能取消已发出的奖励。请找技术团队（Console）调整那个小组的余额，调整会留下记录。
:::

## 8. 倒计时、排队进礼堂、被锁住

:::{important}
这是营会的**突击活动**，营员的说明里没有这一部分。请不要事先告诉营员。
:::

活动开始后，小组的手机会自己跳出窗口，他们会来找你。你需要知道他们看到什么、你要做什么。

### 红色倒计时

小组手机上会跳出红色的倒计时（中间的大数字是剩下的时间）。他们按 **确定** 只是把窗口收起来，**倒数不会停**；
画面上会留一个小倒数标签，点它可以再打开。小组要在时间内来找你，由你在他们的手机上按 **解锁**、输入密码。

- 倒数进行中，小组**不能 Check In** 新的关卡（扫 QR 会显示「倒计时进行中」）。
- 如果倒数时小组在关卡里，限制会等他们 Check Out 之后才生效。

### 时间到了：活动受限

没在时间内输入密码，小组的手机会变成红黑色的 **ACTIVITY RESTRICTED** 画面，不能转钱也不能做别的事。
他们会把手机交给你：

1. 在他们的手机上按 **解锁**。
2. 在跳出的窗口输入 **Game Master 解锁密码**（技术团队会事先告诉你），再按 **解锁**。

解锁之后画面会自己回来，小组也会排进礼堂的队伍。

画面上 **自动解除** 后面的数字是剩下的时间：如果一直没有人输入密码，时间到会自动解除，钱包和 Check In 都会恢复，
但小组**还没有**排进礼堂的队伍。这时他们画面下方会有橙色的 **限制超时** 标签：点它，再输入密码，就会排进队伍。

### 排队进礼堂

输入密码之后，小组会排进礼堂的队伍：**不看时间，只看座位**。礼堂满了就等，有空位就轮到排在最前面的小组。

- **排队中**：小组手机上会跳出「你们在排队进礼堂」的提醒，写着第几位和预计等候时间；之后画面下方有一个小标签
  「排队进礼堂 第 N 位」。这时手机照常能用，可以继续玩。
- **轮到了**：手机变成深绿色的 **你们在礼堂里** 画面，暂时锁住，小组要马上去礼堂。
  如果轮到时小组还在你的关卡里，他们会看到「轮到你们进礼堂了」：请他们先 Check Out（先发完奖励！），再去礼堂。
- **到了礼堂**：节目组签到之后，圆圈才开始倒数礼堂时间；快结束时会变黄色。
- **出来之后**：节目组按 **完成**，手机会自动解锁。倒数到 0 **不会**自动解锁。

深绿色的 **你们在礼堂里** 画面没有解锁按钮，你的密码在那里用不上，要等节目组按 **完成**。
