# 节目组 Event Team：Danger 序列和礼堂排队

分批开始 Danger 倒计时、管理礼堂排队、小组到礼堂时签到开始计时、小组出来时按完成。

## 1. 打开 Event Team 页面

在工作电脑的浏览器打开 Event Team 网址（技术团队会给，通常是那台电脑的 `:8900`）。
这一页是给电脑大萤幕用的；手机只用来开签到页（第 7 节）。

- 不需要登录，打开就能用；只在营会网络（同一个 Wi-Fi）里打得开，不要放到对外网址。
- 管理员也可以从 Console 的 **Event Team** 分页进入：内容一样，另外多一个 **重置序列**（彩排用），但没有签到页。
- 标题旁边的 **(i)** 是说明，点一下就会显示。
- 建议只让**一台电脑**负责编辑名单和按开始，其他人用手机签到页，避免互相改来改去。

:::{warning}
这一页没有密码，连到营会 Wi-Fi 又知道网址的人都能操作。只把网址给节目组的人。
:::

## 2. 先看懂整个流程

现场有两个互相独立的系统：

- **Danger 序列**：所有小组分成几个批次。你按一次开始，每一批依次收到 Danger 倒计时。
  小组在倒计时内找 Game Master 输入密码，就会排进礼堂的队伍。
- **礼堂排队**：像取号排队。礼堂最多同时进 8 组（以现场设定为准）；有空位就叫排在最前面的小组进去，他们的手机会锁住。
  他们到了礼堂，你按 **开始计时**，礼堂倒计时才开始；他们出来，你打勾 **完成**，下一组马上被叫进去。

排队不看时间，只看座位：谁先排进来谁先进，礼堂满了就等。

画面从上到下：右上角三个按钮（**编辑 Danger 名单**、**签到**、**开始 Danger 倒计时**）、**时间线**、
**排队系统**（在礼堂 / 排队中 / 已完成）和小组名单与流程图。画面每几秒自动更新。

## 3. 编辑 Danger 名单：分批次

开始之前，每一个小组都要先分到一个批次。按右上角 **编辑 Danger 名单** 打开大窗口（按钮上的数字是「已分配 / 全部」，分完会变绿）。

- 左边 **未分配** 是还没分批次的小组；右边是 **第 1 批**、**第 2 批**……，标题旁的 `5 / 8` 是「现在几组 / 最多几组」。
- **拖**：按住小组拖进批次；同一批里上下拖可以改顺序。
- **点**（手机、平板更好用）：先点小组，再点要去的批次。
- 批次满了放不进去。拖回 **未分配** 可以取消。
- **自动分配** 把还没分的小组按顺序放进还有空位的批次。

全部分好后，窗口上方会写「全部小组都分好了，可以开始」。

## 4. 开始 Danger 序列：只按一次

1. 名单全部分好后，在名单窗口按 **开始 Danger 序列**，确认一次。还有小组没分批次时按钮是灰的。
2. 第 1 批马上开始倒计时；结束后等一段时间，第 2 批再开始……直到最后一批。整个时间表在按下的那一刻就排好了。
3. 已经开始的批次不能再改；还没轮到的批次仍然可以拖动调整。

开始时**已经在流程中**的小组（在倒计时、被限制、在排队、在礼堂）会被跳过，不会收到第二个倒计时；
跳过几组会写在时间线那一批的名字下面（例如「10 组 · 跳过 2」）。

:::{danger}
**开始只能按一次，而且是真的发给营员。** 想彩排重来，只有 Console 的 Event Team 分页能按 **重置序列**：
所有小组回到「不在流程中」，名单会保留。
:::

## 5. 时间线：看全场、拖动控制

每一行是一个批次：

- **红色长条** 是这一批的倒计时：还没开始是虚线框，倒数中会边走边填色，结束后是实心。
- **虚线台阶** 是到下一批之前的等待（「等 20 分钟」）。
- **蓝色竖线** 是现在的时间。
- **右边的彩色条** 是这一批的小组现在在哪里：灰＝还没开始、红＝倒计时中、橙＝已限制、深蓝＝排队中、紫＝在礼堂、绿＝完成、灰橙＝限制超时。

序列开始后可以用鼠标拖：

- **拖蓝线＝快进 / 倒退**：往右快进（进行中的倒计时提早结束、下一批提早开始），往左倒退。放开前会预览，放开后会再问一次。
- **拖还没开始的批次＝改它的开始时间**。已经开始的批次拖不动。

:::{warning}
**快进是真的发出、真的限制。** 跳过某一批的开始时间，那一批的手机马上收到倒计时；跳过某一批倒计时的结尾，没输入密码的小组马上被限制。
:::

## 6. 排队系统：礼堂和队伍

- **在礼堂**：上面一排圆点是座位。每一行有名字、状态、礼堂剩余时间、**完成** 开关和垃圾桶。
  名字旁边的 **开始计时** 代表还没签到；**前往中** 代表已被叫号但还在关卡里，从关卡 Check Out 之后手机才会锁住。
- **排队中**：圆圈里的数字是第几位，下面写已经等了多久。**↑** 让他往前一位。
- **已完成**：已经出来的小组，最新的在上面。

**垃圾桶** 把这一组拿出排队系统，回到「不在流程中」（在礼堂里的手机会解锁），每次都会先确认。

## 7. 签到：开始礼堂倒计时

小组被叫进礼堂时手机就锁住了，但礼堂倒计时**不会自动开始**，手机上的圆圈是满的。等他们真的到了礼堂，用以下任一方式开始：

- 主画面「在礼堂」那一行按 **开始计时**。
- 用手机开 **签到页**：按右上角 **签到**（数字是还没签到的组数），或在手机浏览器输入「工作电脑网址/checkin」。
  每个还没签到的小组是一个大按钮；点名字后会用很大的字再确认一次队名，按 **确定开始** 才真的开始，按错就点 **取消**。

同一组只能开始一次，重复点不会重新计时。礼堂倒计时只是给小组看的剩余时间，**倒数到 0 也不会自动解锁**。

## 8. 完成：这一轮结束

小组从礼堂出来后，在他那一行打勾 **完成**：手机自动解锁，这一行移到 **已完成**，空出的座位马上叫下一组。

- 忘记打勾，小组会一直被当成在礼堂里，手机一直锁着，后面的人进不来。
- 打错了：到 **已完成** 把勾取消，他会回到礼堂、手机重新锁上（只有最近一次可以取消）。

## 9. 手动 Danger 倒计时

右上角红色的 **开始 Danger 倒计时** 会先问你用哪种方式：

- **按 Danger 序列**：等于第 4 节的开始按钮。
- **手动选择小组**：不管批次，现在就对选中的小组开始倒数（例如补一个漏掉的小组）。名单只列出「不在流程中」的小组，可以多选；
  **讯息** 可以不填（会用预设的）；按 **开始倒计时** 再确认一次。

整批请用名单和开始按钮，手动按钮只用来补漏。

## 10. 常见状况

| 状况 | 怎么办 |
| --- | --- |
| 开始 Danger 序列的按钮是灰的 | 还有小组没分批次；打开名单按 **自动分配** 或手动拖。 |
| 想让流程快一点 / 慢一点 | 拖蓝线（右快进、左倒退）；只改某一批就拖那一批的红框。 |
| 某一批少了几组收到倒计时 | 他们开始时已经在流程中，被跳过了；需要时等他们回到「不在流程中」再用手动倒计时补发。 |
| 小组一直没排进队伍 | 要在倒计时内由 Game Master 输入密码；被限制的请 Game Master 解锁，之后会自动排队。 |
| 小组显示「限制超时」 | 限制已自动解除但还没排队；请 Game Master 在他手机上点橙色 **限制超时** 标签、输入密码。 |
| 礼堂有空位，队伍里的人没被叫 | 他可能同时被别的倒计时盯着，系统先叫下一组；他的名次还在。 |
| 手机还显示圆圈是满的 | 还没人按他的 **开始计时**；按完等几秒手机会更新。 |
| 误按了 **完成** | 到 **已完成** 取消勾选。 |
| 手机打不开签到页 | 确认连营会 Wi-Fi，网址是工作电脑网址加 `/checkin`；还是不行找技术团队。 |
