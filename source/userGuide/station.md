# 关主 Station：关卡笔电的萤幕

关卡笔电上的那一页：显示 QR 让小组打卡、显示谁在关卡里、让小组回答问题。

## 1. 打开 Station 页面

每一个关卡有自己的网址（Station link，长得像 `http://…:8800/s/…`），由技术团队给你。

1. 在关卡笔电的浏览器打开那个网址。
2. 按 **F11** 全萤幕，让小组看得清楚 QR。
3. 整场不用关，画面会自己更新。笔电盖上再打开，画面会马上追上最新状态。

:::{warning}
**这个网址不要外传。** Station 页面会显示关卡的打卡 QR，网址流出去，等于任何人都能帮别人打卡。只在关卡笔电上打开。
:::

打不开（显示找不到网页）？Station 页面只让营会网络里指定的电脑打开，请技术团队确认这台笔电有没有被允许。

## 2. 画面三个区块

- **右上：空位。** 大数字是还剩几个位子，旁边 **共 N** 是最多能进几个小组，下面一个圆点是一个位子（黑色＝有人）。
  有位子时显示 **开放**，满了显示 **已满**，这时小组再扫也进不来，要等人出去。
- **左：在线小组。** 现在在这一关里的小组：表情、组名、待了多久、目前分数，旁边是 **回答问题**。有人进出，几秒内就会更新。
- **右：QR。** 小组用手机扫这个 QR 就打卡进来，再扫一次就打卡出去。QR 下面的小字是同一个网址，
  门口的 NFC 标签也是它，扫 QR 和贴标签效果一样。

## 3. 回答问题（有开答题的关卡）

1. 小组按自己名字旁的 **回答问题**。
2. 输入题卡上的 **题号**，按 **加载题目**。
3. 画面出现题目，填答案后按 **提交**，马上知道对或错，分数自动加上去。
   答错时画面会写 **太大了** 或 **太小了**；答对时会写出正确答案和这题答了几次。

## 4. 答题规则

- 答案可以有一点误差：每一题有自己的可接受范围，落在范围内都算对。
- 答对、答错都有分，只是分数不一样。
- 答错之后要选一个，选好之前这个小组不能换别的题：
  - **Retry**：从小组的钱包扣钱（按钮上写着要扣多少），这次答错的分数不算，再答同一题。画面会继续提示往大还是往小，并写出上一次的答案。
    还没想好可以按 **稍后回答**，下次回来按 **继续**，不会再扣一次。
  - **放弃（Give Up）**：这时才把答错的分数计入，这题不能再答，画面会显示正确答案。
- 答对过或放弃过的题目不能再答，再输入同一个题号会被挡下，换一题就好。
- 没有题数限制，做到全部答对或放弃为止。

:::{note}
Station 页面没有登录，也没有密码，所以答题时请由 Game Master 或关主陪着小组操作，避免有人替别人答题。
:::

## 5. Station 页面不能做的事

Station 页面只做两件事：显示 QR / 名单，以及答题。不能在这里改分数、转钱或把人放出关卡。

| 要做的事 | 去哪里 |
| --- | --- |
| 把人放出关卡 | Game Master 页面的 **Release** |
| 帮小组 Check In（手机没电、扫不到） | Game Master 页面的 **Check In** |
| 发奖励 | Game Master 页面的 **Wallet** |
| 改分数 | 找技术团队用 Console 改 |
