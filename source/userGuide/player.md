## 1. 登录 Sign In

用手机浏览器打开 **game.scmcqqcamp.com**（iPhone 用 Safari，Android 用 Chrome），会看到登录画面：

- **组名**：你们小组的名字。
- **组长的IC前6位**：组长 IC 的前 6 个号码。

填好后按 **Sign In**。登不进去就找 Game Master，**不要一直乱试**：连续输错几次，帐号会被暂时锁住。

## 2. 把网站加到主屏幕

加到主屏幕之后，网站就像一个 App：点主屏幕上的图标就打开，不用每次输网址。

`````{tabs}
````{tab} iPhone（Safari）
1. 用 **Safari** 打开 game.scmcqqcamp.com。
2. 按画面下方中间的 **分享** 按钮（方框加向上箭头）。
3. 往下滑，按 **添加到主屏幕**。
4. 右上角按 **添加**。主屏幕上就会出现 QQ Camp 的图标。

一定要用 Safari，其他浏览器（例如 Chrome、微信里打开的网页）没有这个选项。
````
````{tab} Android（Chrome）
1. 用 **Chrome** 打开 game.scmcqqcamp.com。
2. 按右上角的 **⋮**（三个点）。
3. 按 **添加到主屏幕**（有些手机写 **安装应用**）。
4. 按 **添加**。主屏幕上就会出现 QQ Camp 的图标。
````
`````

## 3. 第一次进来：提醒和 Welcome On Board

登录后可能会先跳出窗口：

- **提醒**：营会发给你们的消息，看完按按钮关掉。
- **Welcome On Board**：欢迎卡。按 **出发吧！** 会开始一段简短的导览：画面变暗，只亮着一个地方，
  旁边的小卡片说明它是什么，按 **下一步** 继续。导览会从钱包走到 Game Stations，介绍余额、转钱、
  转帐记录、楼层、地图按钮、You are here、NFC 按钮和通知铃铛。
  不想看就按 **跳过教程**。之后想再看一次，可以从通知铃铛里重新打开欢迎卡（见第 6 节）。

## 4. 认识画面

上面一排有两个分页，整场营会只会用到这两个：

- **QQ-TNG**：你的钱包，看余额、转钱、看转帐记录。
- **Game Stations**：关卡地图，看关卡和自己现在在哪一关。

分页的右边有两个小按钮：**NFC**（贴关卡的 NFC 标签打卡，见第 8 节）和 **铃铛**（通知记录，见第 6 节）。
最上面是你们小组的表情、组名和 **Sign Out**。每个小组有自己专属的表情，转帐记录和地图上看到的就是它。

画面会自己更新，不用一直下拉刷新。

## 5. QQ-TNG：余额、转钱、转帐记录

### 看余额

**可用余额** 就是你们现在可以用的钱。如果出现「钱包被锁住」，代表你们的活动暂停了，这时不能转钱，请找 Game Master。

### 转钱给别的小组

1. **To 小组**：按 **选择小组**，从弹出的名单挑要收钱的小组（每组前面有它的表情）。
   名单最下面 **Game Masters** 是关卡负责人，交入场费、罚款时选这里。
2. **金额**：填要转多少。
3. **注释**：写用途，可以不写。
4. 按 **转钱**。

:::{warning}
**转出去就收不回来。** 系统没有「取消」。按之前看清楚组名和金额；转错了只能请对方转回来。
:::

### 转帐记录

每一笔钱都记在 **转帐记录**，由新到旧：绿色 **+** 是收到的钱，红色 **−** 是转出去的，
Game Master 发的奖励和系统调整也会列在这里。怀疑少了一笔钱，先来这里看，再拿给 Game Master 看。

## 6. 通知：Enable notifications 和铃铛

### Enable notifications

第一次进来建议先按 **Enable notifications**，手机问你时选 **允许**。这样营会通知你们时，
手机会直接跳出提醒，不会错过。iPhone 要先把网站加到主屏幕（第 2 节），从主屏幕图标打开，才能收到通知。

### 通知铃铛

分页右边的 **铃铛** 是 **通知记录**，最新的在最上面。铃铛上有红点，代表有新的通知还没看。

- **提醒** 和 **Welcome On Board** 可以点开再看一次（欢迎卡点开会重新跑一次导览）。
- 其他通知只会写什么时候、怎么结束，不能再打开。

## 7. Game Stations：用地图找关卡

这一页整个画面是营会的楼层地图：

- **圆点是关卡**：灰色＝没有人；点上的表情＝现在在里面的小组。点一下圆点，会弹出这一关的名字、几个人 / 最多几个人和谁在里面。
- **左边的楼层按钮**（LG、C1、H1……）换楼层。
- **拖动** 移动地图，两指张开 / 合起放大缩小，也可以按 **+** 和 **−**。
- 最下面的按钮：**所有 Stations** 拉出关卡列表（名字、谁在里面、还剩几个位子）；**回到我的 Station** 跳回你所在的关卡；**显示整张地图** 缩回看整层楼。

关卡满了就要等，等里面的人出来才进得去。

## 8. 进关卡 / 出关卡：扫 QR 或贴 NFC

关卡的笔电萤幕上有一个 **QR**，门口还可能有一张 **NFC 标签**，两个是同一个链接，效果一样。

- **进去（Check In）**：用手机相机扫 QR，或贴 NFC 标签（见下面）。成功后 Game Stations 会出现
  **You are here** 小卡片，写着关卡名字和进去多久，地图也会对准那一关。
- **出来（Check Out）**：再扫一次同一个 QR / 贴一次同一张标签，或按 You are here 卡片上的 **Check Out**。

### 用 NFC

`````{tabs}
````{tab} Android（Chrome）
1. 用 **Chrome** 打开网站（要用 https 的 game.scmcqqcamp.com），手机设定里的 **NFC 要打开**。
2. 按分页右边的 **NFC** 按钮，会跳出一个读卡动画。
3. 把手机背面贴近关卡的 NFC 标签，读到后会自动 Check In（已经在这一关就会 Check Out）。
4. 不用了按右上角的 **×** 关掉。

第一次 Chrome 会问能不能用 NFC，请选 **允许**。如果看到「NFC 权限被拒绝了」，到 Chrome 的网站设置里允许 NFC 再按一次。
````
````{tab} iPhone
iPhone 不让网页读 NFC，所以 **不用按任何按钮**：

1. 解锁 iPhone，把手机**顶部**靠近关卡的 NFC 标签。
2. 画面上方会跳出一个通知，点一下。
3. Safari 会打开链接，帮你 Check In（或 Check Out）。

第一次需要在 Safari 登录一次。按网站上的 NFC 按钮只会显示这段说明。
````
`````

## 9. 常见状况

| 状况 | 怎么办 |
| --- | --- |
| 登不进去 | 检查组名和组长 IC 前 6 位；输错太多次会被暂时锁住，找 Game Master。 |
| 手机跳出没见过的窗口、或画面被锁住 | 照画面上写的做，或把手机拿给 Game Master。 |
| 扫了 QR / 贴了标签没反应 | Android 确认 NFC 有开、萤幕没锁；iPhone 要先解锁、贴手机顶部。或改扫关卡萤幕上的 QR。 |
| 「这个 Station 满了」 | 等里面的小组出来再进。 |
| 「请先从目前的 Station Check Out」 | 你们还在别的关卡里，先在那一关 Check Out。 |
| 不小心 Check Out 了 | 再扫一次 / 贴一次就进去了，进出次数没有限制。 |
| 没收到通知 | 按 Enable notifications 并允许；iPhone 要从主屏幕图标打开网站。也可以看铃铛里的通知记录。 |
| 跳出「需要清除缓存」 | 按 **好**，画面会重新载入，钱包不受影响。 |
| 画面卡住 / 空白 | 重新整理网页；还是不行就重新登录一次。 |
